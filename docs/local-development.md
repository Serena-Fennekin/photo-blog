# 本地摄影网站

## 启动

```powershell
npm install
npm run dev
```

项目自带独立的 Node 22 开发依赖。npm 脚本会优先使用它，电脑全局 Node 20.18 无需更换。首次安装需要联网下载依赖；开发运行本身不需要云服务。

- 网站：`http://127.0.0.1:3000/`
- 管理入口：`http://127.0.0.1:3000/admin/login`

开发服务默认绑定 `127.0.0.1`。请前后台统一使用这个地址；`localhost` 和 `127.0.0.1` 的登录 Cookie 不共享，切换地址后需要重新登录。修改监听地址后须停止旧服务并重新运行 `npm run dev`。

首次从本机进入管理入口，可设置唯一管理员的用户名和密码（至少12个字符）。创建后初始化接口自动关闭。不要把密码发送到聊天或提交到 Git。生产环境禁用网页初始化，使用交互式命令 `npm run admin:create -- 用户名`，该命令不覆盖已有账号。

## 添加自己的照片

1. 登录后台直接进入“照片管理”，选择或拖入多张 JPEG、PNG、WebP 照片。
2. 单张最大25MB、5000万像素，每次选择最多100张；总照片数量不受此批量选择限制。逐张上传与处理，失败项可以单独重试，成功照片保留为各自的草稿。
3. 点击照片的“编辑”，填写它自己的标题、拍摄日期、地点、短句、说明、替代文本及分类。每张照片都可独立保存、发布和撤回。
4. 也可在照片网格中多选，批量发布、撤回、统一分类或移除。统一分类会替换所选照片的当前分类。拖动卡片调整整个摄影集的顺序，松开后自动保存；也可用Tab聚焦卡片，再用上下方向键排序，保存后保留焦点并反馈当前位置。卡片用绿色标识已发布、琥珀色标识草稿，同时保留状态文字。
5. 所有已发布照片平级显示在摄影集，点击可查看EXIF，并在整个公开摄影集中前后浏览。移除采用软删除，数据库行和原图保留，暂不自动清理媒体。

分类页支持新增、改名、顺序和停用。首页仅保留引言和进入摄影集的入口，照片统一在摄影集浏览。示例内容在首次运行自动导入；需要空站点时，在第一次启动前将 `JOURNAL_SEED=false`。

现有“首页设置”的精选选项和已保存选择继续保留，当前简洁首页不展示精选照片，不会因此修改照片或丢失原有设置。摄影集转场保留相机和光圈动作，幕布跟随当前主题沿弧面进入和退出；导航未完成时保持覆盖，摄影集和关于我使用同一全站页脚布局。

上传会按原文件的SHA-256指纹识别完全相同的文件，改名不影响识别。重复项显示提示和已有照片入口，不会新增草稿，也不影响同批其他文件。已发布照片重复发布时显示跳过反馈；旧库中的重复草稿也不能再次发布已有的相同公开照片。重新压缩或导出的相似照片不做图像相似度判断。移除的照片可以重新上传。

旧照片会在启动时从现存私有原图建立指纹；原图缺失不会阻止网站运行。新版本会一次性清理旧照片和分类中的旧城市文案，不修改原图、EXIF、查看量或发布时间；后续作者自己填写的地点不受限制。升级前先运行备份命令。

上传选择不产生任何持久化的组或批次。旧记录网页仅重定向到摄影集，旧编辑网页重定向到照片管理，相关组图API已删除。拍摄时间保留相机原始时间及可用时区，历史UTC数据按上海时区还原显示，不随访客电脑时区改变。

## 网站文案与个人动态

后台“文案设置”可编辑首页引言、入口文字，以及关于我的标题、签句、作者名称、一句简介和介绍。保存后刷新前台生效；内容按纯文字显示，换行保留，空行划分介绍段落。旧版精选设置折叠保留，当前首页不展示精选照片。

“动态 → 写一条动态”支持可选标题、正文、话题和最多9张图片。配图支持JPEG、PNG、WebP，每张最大25MB；上传顺序就是展示顺序，可移除后重新选择，不会自动加入摄影集。正文支持换行和表情，不执行HTML或脚本。

- 保存草稿：仅后台保留，不对外展示。
- 公开后发布：在“关于我”的动态墙按发布时间倒序展示，访客可点开配图。
- 私密：仅在后台登录后可看，公开列表、单条接口和配图链接均不可访问。已被访客下载或截屏的内容无法收回；新的动态图片响应不缓存，改为私密后新的请求立即校验权限。
- 移除动态：关闭公开入口和图片访问，保留软删除记录、原文件及未使用的上传资源，不自动清理磁盘。

动态进入可见区域约1秒后请求记录浏览，同一访客/同一动态24小时内只记一次；转场、大图或隐藏标签页会暂停并在恢复可读后重新计时，首次页面响应先建立访客标识以避免多条动态并发重复计数。这是近似浏览统计，并非反作弊访问审计。公开列表每页10条，底部按钮加载更早记录。未发布任何动态时前台显示空状态，不会自动发布虚构示例。

新增数据表与原有照片库共用SQLite备份。既有照片、EXIF、分类、账号和计数不迁移或覆盖。备份数据库时也需要另行保管`storage/`原图及展示图目录。

后台HTML与接口均禁止缓存。文案读取失败时暂停编辑/保存，点击“重新加载文案”成功后再修改，避免将默认文字误写覆盖原内容。

## 背景与转场

前台顶部“特效开/关”控制背景，并在当前浏览器保存选择。深色显示星点、偶尔划过的流星；浅色显示轻雨、涟漪、鱼、荷叶和荷花。使用本地Canvas绘制，无第三方素材请求；绘制上限30fps，限制像素密度和粒子数量。后台、照片大图、转场及浏览器后台标签页中停止绘制；系统要求减少动态效果时也停止。

深色背景增加明暗、大小、冷暖不同的星点与光晕，桌面最多5条错时流星轨迹。浅色背景加入低分辨率水面明暗模拟，鼠标移动会产生连续扩散的涟漪，点击有较明显的水滴；配有细化的叶脉、水珠、层叠花瓣、锦鲤、蜻蜓、白鹭和远处亭台。水波网格最多25200格、交互波纹最多48组、绘制画布约250万像素，移动端按屏幕缩减景物尺寸；这是本地绘制的插画化荷塘，没有加载外部图片素材。

大屏“关于我”使用90vw/最大1920px双栏，正文在宽屏提升到20px；摄影集最大2048px。分类栏随页面滚动离开，不悬浮覆盖照片。手机恢复单列。

摄影集相机转场正常约1.9秒，页面尚未完成导航时会保持覆盖；关于我的骑行转场保留。

## 备案信息

页脚中央预留备案位置，未配置时显示“备案信息待更新”。备案完成后，在 `.env` 中将 `NUXT_PUBLIC_ICP_NUMBER` 设置为实际备案号并重启应用；页面会显示该号码并链接至官方备案查询网站。不要填写虚构号码。

## 旧数据迁移

首次打开旧数据库时，应用先在 `data/backups/` 保存 `before-flat-photos-*.sqlite` 一致性备份，再以事务转换为独立照片。照片ID、文件路径、EXIF、浏览量、分类、账号和会话保持不变；原记录的标题、日期、地点和随笔复制到各张照片自己的字段，原有照片说明保留，可分别编辑。

原先草稿或删除的内容不会变成公开照片；原记录因封面失效而整体隐藏的照片也会保留为草稿。处理失败项不会自动发布。迁移失败会回滚，再次启动不会重复导入；运行中的新模型没有组图表、组封面或上传批次实体。

## 数据和图片

- SQLite：`data/journal.sqlite`，WAL 模式，包含内容、管理员、会话和浏览量。
- 私有原图：`storage/private/`，没有公开HTTP路由。
- 展示图：`storage/public/<照片ID>/640.webp`、`1280.webp`、`1920.webp`。小图不放大；清除图片中的EXIF，只公开经过白名单处理的相机参数。
- 所有目录已被Git忽略。更换电脑需同时迁移数据库和storage目录。
- 查看量在灯箱图片实际加载并可见后计数；同一匿名访客同一照片24小时内只计一次。它是近似统计，不是防刷流量账单工具。

```powershell
npm run backup
```

该命令通过SQLite `VACUUM INTO` 生成 `data/backups/` 下的一致性数据库备份，不复制原图。还应单独备份 `storage/`。恢复时先停止应用，将备份数据库恢复为 `data/journal.sqlite`，确保没有与旧库混用的 `-wal`、`-shm` 文件，再启动应用；操作前保留原目录副本。

## 验证

```powershell
npm test
npm run typecheck
npm run build
npm run test:local
```

`test:local` 在3131端口启动独立验收服务，数据写入 `.superpowers/local-e2e/`，测试账号仅属于该隔离服务。不会写入你的 `data/` 或 `storage/`。浏览器测试需要已安装Chrome。

运行 `build` 前先停止开发服务，以免触发Nuxt的构建目录锁。需要保留开发服务时，可先设置 `$env:JOURNAL_BUILD_DIR='.superpowers/production-build'`，再运行构建；该设置只影响当前终端。

## 当前边界

这是可用的本地版本。图片处理由本机串行执行；上线2核2G服务器前，按OSS部署计划将上传与展示图处理迁移至OSS，再配置CDN、HTTPS、备份轮转与生产告警。当前未开放原图下载，也未接入付费云资源。
# 页面动效与浅色主题

浅色采用水青灰底色，导航透出同一层水面。首页文案逐字缓缓升起，整段约3秒，长文案的错峰时间有上限。摄影集使用约1.1秒的光圈展开转场：导航下方由闭合叶片覆盖，再从中央逐渐露出照片，叶片互相遮叠以避免从边缘漏出长缝，转场期间照片也可点击。再次导航会取消旧动效，旧计时器不会覆盖新页面状态。之前的相机动画保留在 `app/components/site/CameraTransition.vue`，当前入口使用独立的 `ApertureTransition.vue`。

背景在转场中继续运行；骑行翻页复用背景画布的纹理，不另建粒子模拟。特效关闭、隐藏页面、照片弹窗和系统减少动态效果时仍暂停。减少动态效果时文案直接可读，也不播放页面转场。

光圈目前使用可复用的GPU画布，逐片旋转退出，避免大屏多层SVG裁剪重绘；GPU不可用时采用有限分辨率的Canvas2D。性能数据和复测命令见 [光圈性能记录](performance/iris-2026-10-30.md)。

## 个人资料和动态工作台

后台“文案设置”可修改作者名称并选择头像。头像支持JPEG、PNG、WebP，最大5MB，保存后在侧栏与动态卡片共用；服务器生成192px WebP并清除源元数据。已处理头像在修改文案时不会再次压缩，也可切回文字头像。旧文案数据无需手工迁移。

动态编辑器可添加话题，新增话题保存在SQLite的`post_topics`表；内置四项继续可用。完整话题目录需要管理员登录，公开接口只返回已公开动态使用的话题名称。动态日期使用Asia/Shanghai显示到分钟。发布后返回动态列表；草稿保留编辑入口。后台操作消息在顶部显示约2秒，悬停或聚焦时暂停，错误详情仍保留在表单内。

电脑端“关于我”采用独立动态滚动区，保留原有Lenis阻尼；顶部和个人资料不随动态列表移动，过长的个人介绍可单独浏览。手机、平板与系统减少动态效果时使用原生滚动。离开页面会释放滚动控制器、观察器与监听器。卡片采用通透底色和独立绘制的主题角饰，未增加组件库或额外的背景模拟。

### 交互、加载反馈与荷塘素材

首页保留逐字入场，随后以8.4秒周期轻微呼吸；只改变透明度和2px位置，不缩放字形或改变排版。支持鼠标的设备上，信息卡片悬停轻抬3px；拖动照片时不抬起。系统减少动态时保持静态。

导航和控件采用半透明磨砂、静态SVG局部折射与交互高光。折射只用于小面积控件，卡片使用较轻的模糊；不支持相关效果的浏览器仍有带底色的可读表面。手机顶部保留不透明底色，以免滤镜改变固定底部导航的定位。

摄影集、动态和后台列表使用真实请求状态显示骨架、错误重试或带SVG插画的空状态；编辑器等待已保存的数据后才允许保存。图片占位保留尺寸，失败时显示提示。分类切换会忽略旧分类迟到的分页响应。界面分类中的表情转为SVG，原分类名和动态正文保持原样。

荷塘的三种缺口叶片、白鹭、莲苞和虾壳绘图在场景初始化时缓存。虾的轨迹连续，触须与足部单独活动，手机数量较少。主Canvas仍保留原来的250万像素预算及关闭特效、隐藏页面、模态查看和减少动态时暂停的行为。
