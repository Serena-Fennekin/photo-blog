# 独立照片摄影集

本规格取代此前设计中有关组图、记录详情与组封面的部分，依据用户2026-10-27的明确修正执行。

- 照片是唯一内容实体：独立标题、拍摄日期、地点、短句、分类、发布状态、顺序、EXIF与查看次数；没有所属组、组名称、组封面或组内顺序。
- 批量上传是一次操作，不产生持久化的批次/组。每张照片可独立编辑、分类、发布、撤回和移除，也可多选批量操作。
- 摄影集平级展示全部已发布照片，灯箱前后浏览整个公开摄影集。首页按独立照片呈现时间与短句，并保留手动首屏主图/最新发布照片开关。
- 迁移保留旧照片ID、文件、EXIF、查看次数、分类、发布状态和现有管理员。旧组的日期、地点和随笔复制为照片自身属性；保留已有照片说明。迁移前备份，迁移必须原子且可重复启动。
- 删除旧内容类型、组图页面、组件和API。旧浏览地址仅重定向到摄影集/管理首页，不保留组查询。
- 主导航字号20px，分类名称18px；移动端保持可点击且不溢出。保留主题、已确认的转场、阻尼与图片完整适配。
