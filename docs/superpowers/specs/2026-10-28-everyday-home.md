# 日常相册首页与重复照片反馈

用户要求：重复照片应有提示；清除中英文城市名；首页只展示少量精选；邀请文案放到第二屏；首屏去掉尖顶照片并使用轻松日常的文案。

本轮由当前会话继续 Native 实现，不改已确认的转场与全局滚动。

## 设计决定

- 首屏文案“看见喜欢的，就拍下来。”；副文案直接描述花草、小动物、散步风景。避免摄影宣言、大文件名标题与光影主题。
- 保留已有配色以兼容已确认转场：纸色 #eeeae0、浅纸 #f8f5eb、墨绿 #1b2923、灰绿 #778078、陶色 #b96139。陶色仅用于既有功能强调。
- 使用现有中文宋体作为柔和标题、系统黑体作为说明；标题降至舒适的 40–64px，不使用巨大英文标签、光晕或编号。
- 首屏改为居中相册页：上方标题与短说明，下方完整自然比例照片，平直边缘，日期作为小注；不把照片裁成拱门。
- 对比保留原来的左右分栏，仅改圆角会保留原先巨大宣言的观感，因此采用居中相册页；不做多图首屏，避免与下方精选重复。

```text
桌面：导航 / 标题 + 短说明 / 居中完整照片 + 日期
      第二屏邀请文案 / 两列精选（自然宽高）/ 关于入口
手机：导航 / 标题 + 说明 / 居中完整照片
      第二屏邀请文案 / 居中单列精选 / 关于入口
```

## 功能与数据

- 首页设置增加精选多选，上限 6 张，只能选择已发布照片；未设置时取最近排列的 4 张。摄影集仍展示全部已发布照片，精选撤回后不再公开。
- 按原始文件 SHA-256 检查完全相同的文件，包括改名文件。重复返回 409 和已有照片入口，不新增草稿，不影响同批其他文件。不同内容同文件名正常上传。移除的照片允许重新上传。
- 原有本地原图建立指纹，不变更照片编号、原图、EXIF、查看数、登录账号。发布已经发布的照片为幂等操作，后台显示跳过数量。
- 清理当前网站固定文案、演示数据与既有照片/分类的可见城市字样；一次性清理不禁止作者未来自行输入地名。保留 Git 历史与备份。

验收：独立数据测试重复/旧图指纹/精选上限与撤回；浏览器验证批量重复提示、精选选择、第二屏顺序、桌面两列手机居中、无横向溢出及转场保持正常。
