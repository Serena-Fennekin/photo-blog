# 摄影日记 UI 原型设计笔记

> THROWAWAY PROTOTYPE：三个方案通过 `?variant=A|B|C` 切换，用于回答“主页与摄影集应该采用哪种结构”。

## 视觉基线

- 暗房黑 `#202120`：主背景，尽量中性，避免蓝黑科技感。
- 显影纸白 `#EEECE6`：浅色段落与主要文字。
- 胶片标记黄 `#D5C653`：只用于当前选项和极少量交互提示。
- 铅笔灰 `#9B9A94`：说明、EXIF、时间。
- 冲洗槽绿 `#303832`：方案 B 的安静背景。

字体使用系统自带的 `PingFang SC` 与 `Songti SC`，避免国内访问依赖外部字体服务。

## 三种结构

### A · 纵向索引

```text
[固定导航]
[竖排题名] [椭圆主图 + 大标题]
[跳转文字]
[固定分类栏] [双列瀑布流]
```

最接近参考站，但把商业作品集改成个人摄影日记。

### B · 时间章节

```text
[左右分屏首幕]
[日期/短句章节]
[居中文字入口]
[顶部时间筛选 + 三列瀑布流]
```

强调“生活记录”，照片按时间进入，而非先按题材分类。

### C · 接触印样

```text
[极简题名 + 大面积照片序列]
[底片编号式入口]
[浮动分类条]
[密集四列瀑布流]
```

浏览效率最高，像摄影师挑片时的 contact sheet。

## 原则

- 照片是页面结构，不是卡片装饰。
- 文字只承担导航、时间和情绪锚点。
- 首屏只有一次编排动画；其余运动由点击和滚动触发。
- 移动端取消固定侧栏与大幅视差，保留阅读顺序。
