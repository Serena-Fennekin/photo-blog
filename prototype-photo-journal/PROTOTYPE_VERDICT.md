# 原型结论

- 选择日期：2026-10-25
- 验证问题：主页与摄影集应该采用哪种结构？
- 选择方案：B「时间章节」

## 已验证的方向

- 首页以日期、地点、短句和代表照片组成章节，强调持续记录，而非商业作品集。
- 首页中段使用独立的情绪文字作为进入摄影集的入口。
- 摄影集使用瀑布流，点击照片后进入沉浸式灯箱并展示 EXIF 与查看数。
- 摄影集分类保留方案 B 的顶部筛选，不采用固定左侧栏。
- 首页首屏封面支持“手动指定”和“跟随最新记录”两种模式，默认手动指定。
- 自动模式使用最新已发布记录的封面；没有可用照片时保留当前封面。
- 每次发布以一组照片故事为单位，一条记录包含多张照片。
- 组内照片支持排序，并从中指定一张作为该记录的封面。
- 摄影集将各组照片全部混排进瀑布流；点击照片后打开灯箱，可查看 EXIF、浏览同组照片并进入所属记录。
- EXIF 仅公开相机、镜头、焦距、光圈、快门、ISO 和拍摄日期。
- 上传时清除 GPS 精确坐标、设备序列号等敏感元数据；展示地点由后台手动填写城市或区域。
- OSS 私有保存原图母版；网站仅公开压缩并清除敏感元数据后的展示图。
- 后台采用单管理员账号，不开放注册；使用强密码、服务端 Session 与登录限速。
- 前台提供顶部常驻的主题切换控件，包含“跟随系统 / 深色 / 浅色”三种选择，默认跟随系统，并在浏览器本地记忆访客选择。
- “跟随系统”模式会响应操作系统主题的实时变化。
- 后台以组图记录为编辑单位，支持批量直传 OSS、自动提取并清洗 EXIF、拖拽排序、指定封面、预览、草稿与发布/撤回。
- 技术架构采用 Nuxt + Vue + TypeScript 单体应用、SQLite、Caddy、阿里云 OSS（杭州）与 CDN；图片直传和处理不经过 ECS 应用进程。
- 深色绿色调比纯黑更生活化，也能承托暖色照片。
